0.3.5 — 2026-06-09

The repository metadata identifies the current plugin version as 0.3.5. This release added and documented the modular Discord voice bridge, local control sidecar, fallback delegation, notifications, email briefs, webhooks, SFX, video-frame support, and the static documentation site.

Current support boundaries

  • Control API: mutating sidecar routes remain blocked by the authentication defect tracked in Issue #5. The sidecar is intended for loopback use; transcript notes require separate privacy review.
  • Video frames: feeder parsing, secret-file alignment, and authenticated client delivery remain open in Issue #9.
  • Email briefs: backend failure reporting, retry state, recipient routing, and model-visible message data remain open in Issue #10.
  • Installer: deterministic reruns and unattended validation remain under review in Issue #11; literal and atomic credential persistence is tracked in Issue #23.
  • Fallback delegation: portable binary discovery and rate-limit-aware selection remain open in Issue #8.
  • Storage and routing: custom-root SFX and notification paths are tracked in Issue #18 and Issue #20; embedded recipient fallbacks are tracked in Issue #16.
  • Bundled media: redistribution rights for included SFX are unverified; see Issue #12.

Documentation changes

  • Added a static documentation site and linked reference pages for installation, architecture, environment variables, notifications, email, webhooks, SFX, video, and troubleshooting.
  • Subsequent documentation corrections removed deployment-specific identifiers, private control guidance, unsupported licensing claims, stale version labels, broken local links, and capability statements that were not supported by the current runtime.
  • The generated site remains checked into the repository. Changes to scripts/build_docs_site.py must be reviewed together with the complete regenerated output before the generator can be treated as authoritative.

Earlier releases

Versions before 0.3.5 introduced the initial Gemini Live voice transport, interruption handling, local tools, notification and webhook plumbing, email summarization, SFX playback, video-frame ingestion, onboarding/profile persistence, and related tests. Historical implementation details may no longer match the current module layout or safety posture.

Verification guidance. Use the current source, open issues, pull-request diff, review threads, and exact-head CI results when evaluating a change. Historical release text, generated pages, or local benchmark notes should not be treated as current validation by themselves.

Operator checklist

  1. Read Quick start and Troubleshooting.
  2. Keep the sidecar on loopback and do not expose transcript or mutating routes while the linked security issues remain open.
  3. Set deployment-specific user, path, webhook, and secret values explicitly; do not rely on repository defaults for sensitive routing.
  4. Review the repository's open issues before upgrading or enabling optional integrations.
