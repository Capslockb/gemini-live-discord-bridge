Hermes Live

A self-hosted Discord voice bridge with audio, optional tools, notifications, and multimodal integration under active review.

v0.3.4.2 VOPI build self-hosted Gemini Live
status
Review the open issues before deployment. The core voice bridge is under active development. Mutating sidecar routes remain blocked by Issue #5; bundled frame delivery is blocked by Issue #9; email briefs retain delivery and privacy blockers under Issue #10; and the repository license is not yet selected under Issue #7.

What's in the repository

voice

Voice bridge

Discord audio is converted for Gemini Live and returned to the voice channel. Review the architecture and troubleshooting pages before relying on latency or reconnect behavior.

vision

Optional frame input

The model supports image input, but the bundled feeder and built-in frame clients are not operational on current main. See Issue #9.

tools

Configured tool access

Tool availability depends on the host runtime and permission boundary. Do not treat conversational prompt text as authorization for filesystem, network, email, or mutation actions.

delegate

Delegation fallback

Optional CLI delegation and fallback logic is documented, including current portability and rate-limit limitations.

proactive

Notifications

Local and scheduled notification paths are available, subject to the documented sidecar authentication and storage-path limitations.

mail

Email brief

Keep scheduled briefs disabled unless destination, backend state, retry behavior, and model-visible inbox data have been explicitly verified. See Issue #10.

sfx

SFX library

Optional sound-effect slots are supported. Bundled media redistribution rights remain unresolved; use your own licensed assets or disable SFX.

memory

Optional session context

Dynamic context can supplement a session. Treat profile conclusions, identifiers, and session material as sensitive runtime data.

control

Loopback sidecar

The sidecar binds to 127.0.0.1:18943 by default. /health is read-only; mutating routes are blocked pending Issue #5, and /notes exposes stored note/transcript data without authentication.

Get started

Install only after reviewing the current limitations in the quick-start guide.

# 1. Clone
git clone https://github.com/Capslockb/gemini-live-discord-bridge.git
cd gemini-live-discord-bridge

# 2. Review docs/quickstart.md and the open issues

# 3. Install
./install.sh

# 4. Restart the gateway
systemctl --user restart hermes-gateway

# 5. Check anonymous loopback health
curl -s http://127.0.0.1:18943/health | python3 -m json.tool

Use /voice-live and /voice-live-leave from Discord after configuration and runtime validation.
