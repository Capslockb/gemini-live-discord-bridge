Environment variables

Code-grounded reference for the current Gemini Discord voice bridge. Defaults are taken from the current configuration and runtime modules. For protocol details, see Gemini Live implementation.

security
Do not infer a safe deployment from configuration names alone. Mutating sidecar routes remain blocked by Issue #5; /notes exposes transcript data without authentication; embedded identity defaults remain tracked by Issues #16 and #17. Keep the sidecar loopback-only and configure identities explicitly.

Required / strongly recommended

VariableDefaultDescription
DISCORD_BOT_TOKEN—Discord bot token. Required by the Hermes Discord adapter and installer path.
GEMINI_API_KEY—Gemini API key. Required unless GOOGLE_API_KEY is set.
GOOGLE_API_KEY—Fallback Gemini API key used when GEMINI_API_KEY is empty.
DISCORD_VOICE_LIVE_USER_IDrepository-embedded deployment fallbackStrongly recommended. Used for channel inference, target-user presence checks, and default peer naming. The embedded fallback is unsafe for reused or multi-user deployments; see Issue #16.

Sidecar control API

VariableDefaultDescription
DISCORD_VOICE_LIVE_PORT18943Local HTTP sidecar port bound to 127.0.0.1.
DISCORD_VOICE_LIVE_SECRET_FILE~/.hermes/voice-live-control-secretRuntime secret file for X-API-Secret. Current install.sh creates ${HERMES_HOME:-$HOME/.hermes}/control.secret instead, so the installer does not populate the runtime-default path; see Issue #9.
DISCORD_VOICE_LIVE_NOTIFY_TIMEOUT5Timeout for notification-side HTTP/control operations.

The intended policy leaves /health and /notes anonymous and requires X-API-Secret for /stop, /say, /frame, and /notify. On current main, mutating-route authentication is blocked by Issue #5. /notes can return persisted transcript events and the backing file path without authentication; never expose the sidecar through a proxy or browser-facing network path while Issue #4 remains open.

Honcho / profile context

VariableDefaultDescription
VOICE_LIVE_HONCHO_CONTEXTtrueInject Honcho context into the conversational context.
VOICE_LIVE_HONCHO_MAX_CHARS1200Maximum Honcho context characters.
VOICE_LIVE_HONCHO_PEERHONCHO_PEER_NAME, then user ID, then userOverride the peer name used for memory context.
VOICE_USERS_DIR~/.hermes/voice-users/Per-user profile directory.
VOICE_OWNER_DISCORD_IDrepository-embedded deployment fallbackAuthorization identity for owner-only capabilities. The unsafe default and revocation behavior are tracked by Issue #17.

VOICE_OWNER_DISCORD_ID is authorization state, not display metadata. Changing or unsetting it does not demote a profile already persisted with is_owner: true. Treat ~/.hermes/voice-users/*.yaml as security-sensitive, configure the intended owner explicitly, and review existing profiles before reusing an installation.
